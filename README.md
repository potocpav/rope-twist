# How Climbing Ropes Twist

A blog post on why a climbing rope twists.

**Read it:** https://potocpav.github.io/rope-twist/

Text and analysis by me, code by Claude.

Main page is `index.html` — plain static HTML, no build step.

## Local preview

```sh
python3 serve.py
```

Then open http://localhost:8000/. The page reloads automatically whenever a file in the folder changes, including the figures. Pass a port to use another one, e.g. `python3 serve.py 8080`. Needs only Python 3.

## Backup of the linked article

`kinematics-of-rods/` holds an offline copy of [Kinematics of Rods](https://rotations.berkeley.edu/kinematics-of-rods/) (rotations.berkeley.edu), which `index.html` cites, saved on 2026-10-28 in case the original goes away. It includes the figures, the rendered equations and the page's styles. With `serve.py` running, open http://localhost:8000/kinematics-of-rods/kinematics-of-rods/.
