# How Climbing Ropes Twist

Text and analysis by me, code by Claude

A blog post on why a climbing rope twists.

**Read it:** https://potocpav.github.io/rope-twist/

Main page is `index.html` — plain static HTML, no build step.

## Local preview

```sh
python3 serve.py
```

Then open http://localhost:8000/. The page reloads automatically whenever a file in the folder changes, including the figures. Pass a port to use another one, e.g. `python3 serve.py 8080`. Needs only Python 3.
